# Chapter 12. AWS S3 파일 업로드 (3)

## 1️⃣ S3(Amazon Simple Storage Service)

### ✅ 개념
- 아마존 웹 서비스가 제공하는 클라우드 스토리지 서비스
- 파일, 데이터 및 다양한 유형의 미디어 등을 저장하고 관리하는 데 사용되는 웹 기반 스토리지 시스템

### ✅ Amazon S3의 기능

#### 스토리지 클래스 및 관리

- S3 스토리지는 일반적으로 **어떤 종류의 데이터를 관리하는지, 얼마나 자주 그 데이터에 접근해야 하는지에** 따라 분류
- S3 수명 주기 : 수명 주기 구성을 설정하여 객체를 비용 효율적 저장
- S3 객체 잠금 : 고정된 시간 동안 무기한으로 객체의 삭제 또는 덮어쓰기 방지

#### 엑세스 관리 및 보안

- S3 퍼블릭 엑세스 차단
- IAM : AWS 리소스에 대한 액세스를 안전하게 제어하는 데 도움이 되는 웹 서비스
- 엑세스 제어 목록(ACL) : 인증된 사용자에게 개별 버킷 및 객체에 대한 읽기 및 쓰기 권한을 부여

#### 웹 호스팅 및 정적 웹 사이트 호스팅
- S3를 사용하여 정적 웹 페이지나 웹 사이트 호스팅이 가능

### ✅ 버킷
**Amazon S3에 저장된 객체애 대한 컨테이너**
- 버킷의 이름은 유일
- 버전관리 기능을 통해 사용자에 의한 실수도 복원 가능

### ✅ 객체
**객체는 Amazon S3에 저장되는 기본 개체**
- 객체는 객체 데이터와 메타데이터(이름-값 페어의 집합)로 구성
- S3 버킷에 저장되는 데이터는 모두 객체라 불림

## 2️⃣ MIME Type

### ✅ MIME TYPE(Multipurpose Internet Mail Extensions)
**MIME TYPE은 인터넷에서 전송되는 다양한 종류의 데이터를 식별하기 위한 형식**
- 주로 웹 브라우저가 웹 서버로부터 받은 데이터를 해석할 때 사용
- EX. HTML 문서의 MIME TYPE은 "text/html", JPEG 이미지는 "image/jpeg"
- HTTP 헤더에서 Content-Type 등으로 지정

### ✅ Content Type
**HTTP 통신에서 전송되는 데이터의 타입을 명시하기 위해 header에 실리는 정보**
